# Project Evidence

This directory contains project-specific evidence for the paper:

- status,
- architecture,
- experiments,
- verified measurements (raw Renode/board logs, profiler output),
- implementation notes,
- Vivado utilization and timing reports.

For every result added here, record its source commit, build command,
platform (simulation or board) and date, and update
`../EXPERIMENTAL_RESULTS.md`.

The current synchronized Git branch and verified experimental evidence take
priority over historical notes.
