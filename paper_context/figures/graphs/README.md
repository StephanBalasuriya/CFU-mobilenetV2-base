# figures/graphs

Measured performance, resource and instruction-count graphs, plotted only from `../../evidence/`.

Generated by `../scripts/build_results.py` (`python3 paper_context/figures/scripts/build_results.py`).
Each figure is written as PDF (vector, for LaTeX), SVG and 600-dpi PNG,
sized for one IEEE column (3.5 in), STIX (Times-like) font.

| Figure | Shows | Data | Status |
|---|---|---|---|
| `end_to_end_performance` | Cycles per inference for 1×1 / 1×1+3×3 / +sliding window, split into depthwise, Conv2D, other; speedup vs 1×1 CFU | `../data/end_to_end_cycles.csv` | **Provisional**: CPU-only bar missing; regenerate when the CPU-only log is added |
| `sliding_window_instructions` | 3×3 CFU instructions per inference, before/after sliding window | `../data/sliding_window_instructions.csv` | Analytical counts; caption must say so. Not a speedup |
| `fpga_resources` | CFU LUTs and FFs (post-place), split into 3×3 unit vs rest of CFU | `../data/fpga_resources.csv` | Ready (BRAM/DSP unchanged, state in caption) |

Colours: validated categorical slots 1–2 (+3) of the dataviz reference
palette, plus hatching, so series stay distinguishable in grayscale print.
